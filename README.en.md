# Hiperfoco Support

[Leer este documento en español](README.md)

This public repository is the place to request support and propose improvements related to **Hiperfoco**.

> [!IMPORTANT]
> Issues are public. Do not post passwords, credentials, medical information, personal data, or any other sensitive content.

## Create a request

Choose the appropriate form:

- [Request support](https://github.com/fundacion-hiperactiva/hiperfoco-support/issues/new?template=support.yml): report a problem or ask for help.
- [Suggest an improvement](https://github.com/fundacion-hiperactiva/hiperfoco-support/issues/new?template=feature_request.yml): propose a new feature or an improvement.

Before creating an Issue:

1. [Review existing Issues](https://github.com/fundacion-hiperactiva/hiperfoco-support/issues) to avoid duplicates.
2. Use the appropriate form and provide all requested information.
3. Include clear reproduction steps when applicable.
4. You may attach screenshots, but remove or hide all personal and sensitive data.

## What happens next

The team will review the request, may ask for more information, and will classify it by type and priority. Creating an Issue does not guarantee a resolution time.

## Scope

This repository is exclusively for support and improvement requests. It does not contain the Hiperfoco source code.

## Language

Requests may be submitted in Spanish or English.

## Conduct

Participate respectfully and constructively. Abusive, discriminatory, irrelevant content or content that exposes private information may be removed.
