# Soporte de Hiperfoco

[Read this document in English](README.en.md)

Este repositorio público es el canal para solicitar soporte y proponer mejoras relacionadas con **Hiperfoco**.

Sitio oficial: [www.hiperfoco.dev](https://www.hiperfoco.dev)

> [!IMPORTANT]
> Los Issues son públicos. No publiques contraseñas, credenciales, información médica, datos personales ni ningún otro contenido sensible.

## Crear una solicitud

Elegí el formulario que corresponda:

- [Solicitar soporte](https://github.com/fundacion-hiperactiva/hiperfoco-support/issues/new?template=support.yml): para informar un problema o pedir ayuda.
- [Proponer una mejora](https://github.com/fundacion-hiperactiva/hiperfoco-support/issues/new?template=feature_request.yml): para sugerir una función nueva o una mejora.

Antes de crear un Issue:

1. [Revisá los Issues existentes](https://github.com/fundacion-hiperactiva/hiperfoco-support/issues) para evitar duplicados.
2. Usá el formulario adecuado y completá toda la información solicitada.
3. Incluí pasos claros para reproducir el problema cuando corresponda.
4. Podés adjuntar capturas, pero ocultá cualquier dato personal o sensible.

## Qué ocurre después

El equipo revisará la solicitud, podrá pedir información adicional y la clasificará según su tipo y prioridad. Crear un Issue no implica un plazo de resolución garantizado.

## Alcance

Este repositorio está destinado exclusivamente a soporte y solicitudes de mejora. No contiene el código fuente de Hiperfoco. Para conocer el producto, consultar la guía de uso o acceder a la instalación, visitá el [sitio oficial de Hiperfoco](https://www.hiperfoco.dev).

## Idioma

Podés crear solicitudes en español o en inglés.

## Convivencia

Participá de manera respetuosa y constructiva. El contenido abusivo, discriminatorio, irrelevante o que exponga información privada podrá ser eliminado.
